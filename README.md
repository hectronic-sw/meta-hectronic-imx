meta-hectronic-imx
==================

This Yocto meta layer adds BSP support for the Hectronic i.MX platforms to be 
used together with the official NXP repos:
`https://github.com/nxp-imx/imx-manifest`

The different branches in this repository corresponds to different releases of 
Yocto and the NXP BSP:

| Yocto version | Codename  | Branch    |
|---------------|-----------|-----------|
| 5.2           | Walnascar | walnascar |
| 6.0           | Wrynose   | wrynose   |

And so on.

Build instructions for each branch is found in this README file in respective branch

Since this is based on NXPs BSP, most of the information available in NXPs
documentation is applicable:
[NXP Yocto manual UG10163](https://www.nxp.com/docs/en/user-guide/UG10163.pdf)
and
[NXP Yocto getting started UG10164](https://www.nxp.com/docs/en/user-guide/UG10164.pdf)
